# 制作准备与执行

先读取用户指定项目根目录中的剧本、分镜、纯净稿、视频、录音和音乐库。文件名用于定位，集数和内容以实际素材核对。

分镜至少建立“集数 → 镜号 → 画面动作 → 人物对白 → 旁白 → 对应素材”的映射。TXT、Markdown、CSV、Excel、Word 均按可用工具读取；表格先核对列名，图片/PDF 分镜先识别再核对文本。缺少的素材和不确定映射集中列出，继续可独立完成的集数。

按用户指定目标语言、画幅、字幕样式和音乐要求剪辑。录音包含串读时区分旁白与人物对白，按制作要求保留旁白、视频人物原声和必要环境声。变速、删旁白、镜头取舍按本次要求执行；需要决定剧情取舍时集中询问。

字幕文字用纯净稿校对、时间用最终人声逐词对齐；读取百慕内置返工方法中的标点、分句与复核要求。制作与审核分开：制作完成按要求导出，审核后先汇报人工，再按最终清单返修。

交付目录按用户要求：各集 MP4 集中在“【剧名】卡后导出视频”，数字命名；工程、字幕、报告及过程资料集中在“工作资料”。汇报视频目录、完成集数及需人处理的问题。
