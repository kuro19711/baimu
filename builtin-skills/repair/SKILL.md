# 审后返工方法

百慕「修改」栏的勾选表示人希望处理的具体问题，人可在任务开始前编辑并保存每项最终修改意见。点击「按清单修改」后固定所选问题及当时保存的意见；Codex 以 active_batch.findings[].plan 为本轮最终方法，不重用早期 AI 建议，不用后续未纳入批次的文字替换该快照。只处理该批 findings，不恢复人工取消项或把新问题自动加入本轮。每次修改前读取任务状态，过期或取消后停止；逐项回写修改中、待复审、已解决/未解决。未实际存在的演示问题不能当成真实缺陷执行编辑。写入成功后仍需新成片实际复审。

从当前分集 review-context 读取这份文档和所选审核要求。审核发现与修改授权分开：勾选检查项不表示允许修改。用户说先报告就停止在报告；用户已经授权的操作不反复询问。先审核汇报，由人工选定清单并编辑最终意见，再执行返修。已给出的要求直接采用，仅对缺少关键资料或需要剧情取舍的事项集中询问。

## 定位与保护

每个问题绑定原成片版本、起止时间、字幕/音轨/镜头 ID 和源素材时间。不要拿旧成片时间直接修改已经改变的时间线。先读取当前工程 revision、轨道锁和本机支持的编辑操作；通过百慕接口差量修改，不直接改数据文件或剪映草稿。遇到冲突重新读取并计算，不强制覆盖或回滚整集。
规则或本集选择发生变化时重新读取 review-context；保存使用的 rules_revision 与 scope_revision，不能把旧规则下的结论当作新规则结果。

## 字幕处理

有真实音画证据后只修目标字幕。对已核实可能侵权的名词，按具体标注改成保留语义的泛称或采取用户指定处理；角色姓名不因属于专有名词被替换。保留含义、语气、角色关系、目标语言和时间对应。缺乏可靠试听时不按 ASR 猜测。只改一处不能顺便重生成整集字幕。多样式、动画等不受简易接口支持时保留原生字段，报告能力限制。

### 字幕标点与排版修正

以纯净稿校对文字，只清除用于分句的标点，保留缩写点号、词内连字符、词内撇号和数字中的有效标点；逐处按上下文核实，不能全局删除所有标点。Mr.、Mrs. 等保留，回答句 No. 改为 No；西语、葡语保留问号、感叹号及其实际使用的起始符号 ¿、¡。
去标点与分句分开处理：按词时间、停顿、实际说话气口和语义保持多条字幕。默认字体框实际显示超过两行时，在合理气口拆成两条；若拆分会使最后一个单词单独成条，重新调整相邻分句边界。沿用百慕既有预设效果、字体和框宽，不靠缩小字体或拉宽字体框规避两行要求。检查实际导出的行数和入出点，不用字数推断行数或均分时长。

### 字幕时间修正与制作

1. **先锁定剪辑和声音。** 确定画面、旁白取舍与变速、人物原声和混音位置，记录工程版本和声音版本标记（可用时包括声音指纹）。这里的锁定是固定本轮对齐依据，不擅自改动用户轨道锁或阻止用户编辑。
2. **分别对齐人声。** 使用最终时间轴位置上的旁白音轨、人物对白音轨，分别逐词对齐对应的纯净稿。纯净稿保留实际说出的原语言词句，去除角色标签、舞台说明等非发声内容；不是先改成泛称后的展示字幕。按源素材入点、剪切、变速和摆放位置映射词时间，避免 BGM 干扰。只有“这段有人说话”的活动区间不够，必须知道每句、每个分句何时真正说出。
3. **按说话气口制作字幕。** 结合词起止、停顿及语义分句，控制行数，并保留原语言或已确认译文的对应关系。旁白与对白重叠时，先处理声音冲突或明确字幕显示顺序，不能直接截短上一条字幕来隐藏重叠；声音调整超出固定批次或授权时先记未解决，不擅自扩批。
4. **用最终混音和实际导出 MP4 复核。** 检查文字、入出点与听到的声音；机器对齐负责批量发现偏差，句首句尾、切镜、变速、重叠和低匹配位置仍需实际试听。声音位置、变速或剪辑改变后，重新对齐受影响的字幕，不沿用过期声音标记。

先核实当前接口与工具是否支持分轨提取、逐词对齐及所需速度映射。若只支持最终混音识别或只有语音活动段，明确未满足上述方法，不用均分时长、重抄 ASR 或伪造词时间冒充已完成。仍遵守现有声音/字幕指纹、并发版本和锁轨检查；这些方法要求不等于软件已具备对应自动化能力。

### 未成年人霸凌表达的字幕与声音处理

对已核实涉及未成年人的 bully、mistreat 等禁用表达，按问题标注对对应字幕词句打码，剪掉对应的违规人声音频片段。遮挡以完整盖住目标文字、保留其它字幕的可读性为准，不能只改字幕而保留违规声音，也不能剪掉无关对白、旁白和音乐。音频剪除默认保持画面与其它音轨的绝对位置，不因删除一小段声音把整条时间线吸合前移；复核切口是否产生截字、爆音或新的缺失。
若违规人声与音乐混在同一素材中，先核实能否分离和局部处理，无法可靠操作则报告能力限制，不把整片静音当作已修复。词句处理不自动证明同段画面中的打架或受伤已解决，相关画面问题仍单独复审。

## 音频与音乐处理

确认缺失、叠放或音乐遮盖对白后再调整对应片段和音量。保留正常停顿、独立音轨和用户改过的声音。关联原声仍与画面联动，只改单独声音时按接口要求解除对应联动。配错角色需换配音时生成具体任务，不靠改字幕掩盖错误。不得用静音造成新的信息缺失。

### BGM 调整与复听

本项目音乐从桌面的“音乐”文件夹按剧情情绪选取；已选曲不因审核而自动换曲，只有本轮最终修改意见要求换曲时才选择合适替代。BGM 基础音量约 −11 dB，保持全集统一的 BGM 音量设置；该数值是制作起点，不能把它当作最终响度或不压人声的保证。
以旁白和人物对白清晰可辨为目标。若约 −11 dB 仍压过人声，按本轮最终意见统一降低本集 BGM，复听其它有旁白、对白及较轻人声的位置；不擅自改成逐句忽高忽低的自动压低，不为维持参考数值而放任音乐盖住声音。需要统一调整整集时，在具体修改意见中写清整集 BGM 的影响范围；超出固定批次的授权时先列出待处理方案，不能默默扩大修改。
保留必要环境声、原人物对白和已确认的人声位置，不能用删除人声、整段静音或过度抬高人声造成失真来掩盖问题。修改后回读音轨设置，用最终混音与新导出 MP4 实际复听原问题及相关区间；只改音量且人声位置、变速和剪辑未变时核查同步，若发生位置、速度或剪辑变化，重新对齐受影响的字幕。

## 局部打码

先确认允许以遮挡解决，核对对象区域、出现首尾和运动范围。使用可编辑的局部蒙版及必要关键帧，检查进入、离开、转身、遮挡和切点，不能只查一张截图。模糊力度以实际输出能否消除需处理内容为准，参数写入成功不代表有效。
**画面打码必须羽化，且位于字幕下层。** 蒙版核心区域须持续完整盖住目标内容，羽化边缘不能让目标重新可辨认；结合人物、物体和镜头运动动态调整位置、大小与羽化范围，不用一个固定大框覆盖整个镜头。羽化及其影响范围不得遮挡脸部、字幕或无关关键信息，需检查运动中和关键帧之间的实际结果。当前模型支持相应字段时使用羽化及 `below_captions` 层级；未支持时报告限制，不虚构参数或声称视觉验收完成。
**字幕遮词与画面蒙版分开。** 画面蒙版维持字幕下层，不抬高为覆盖整条字幕。对违规字幕打码，在字幕文字本身或其字幕内部的局部遮挡中实现；字幕替代块须盖住目标字形，不误盖其它文字。若该方式不受当前接口支持，保留明确待处理项，不把字幕下层蒙版当成已遮住字幕，也不无意违反画面蒙版层级要求。
不同集或镜头的同一资产只复用风险线索，逐处确认坐标、大小和时段。不得把一个镜头的坐标直接套到所有集。语义违规、规则要求删除的内容不能只打码。

## 空白时段去除

仅处理已标注并属于本轮固定批次的、持续大于 2 秒且人物反应较小的实际空白区间。保留有意义的情绪停顿、动作与信息，不因无台词或运动量低就直接剪除。去除应精确到确认的空白起止，保护两端词句、反应、动作因果与声音尾音；需要改变画面时长的操作必须在相应授权内。
时长变化后按实际影响重算后续画面、旁白、对白、音乐、字幕和打码位置，检查跨越切点的独立声音，不默认所有轨道自动随动。更新声音版本标记，对受影响字幕重新逐词对齐，并以最终混音和新 MP4 复核节奏及同步。完成空白剪除后再锁定最终剪辑/声音进行该轮字幕对齐，避免先做完字幕又把其时间依据剪掉。

## 删换镜头与重新生成

仅在本次授权包含删换镜头、重生成或改剧情时执行；否则提供具体片段及方案，继续其它可修项目。优先已有合格素材和保持时长的局部替换，保护关键对白、人物关系、动作因果和情绪转折。时长改变时重算后续字幕、音轨、打码与切点，核对原声换源，不默认所有独立轨道都随动。

## 导出与复审

记录修改前后值及对应问题。回读确认工程，再导出新版本并查询真实完成状态。审核烧录了字幕与打码的实际成片，不拿编辑用的干净预览当最终效果。
复查原问题和影响到的上下文、对白、字幕、音乐及切点。状态区分已解决、仍存在、不确定和未复查。没有覆盖的区间不能宣称通过。剪映真实打开、保存、重开和画面验收与 JSON 检查分开报告。
默认同一问题最多自动返工两轮；无改善、互相反复或证据不足时停止该项，给出具体待处理方案，不阻止其它独立问题推进。不要自动上传素材到外部服务或调用未经授权的收费服务。
